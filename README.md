# 無名之物（Interactive Flow Mirror）

互動鏡像裝置原型。鏡子裡是一個全由粒子構成、自己會不規則變化的世界；它從不畫出站在前面的人，人只能從它的反應知道自己在場。

以 Unity 6（URP）與 compute shader 製作。

## 構想

設想中是一面立在地上、4m × 2m 的 LED 牆。實體不會製作，這是個人概念作品。

- 約 20 萬顆光點聚成一個**形體**：有時是柔軟、沿著表面流動的**生物**，有時是有硬輪廓的**殼**，而且會從其中一種連續地變成另一種
- 它自己活著：每次**定形**多久、用哪一種**轉場**換到下一個形態（煙散、流變、蛻變、塌縮、散逸），都不規則；偶爾表面震顫一陣，像要變了，最後沒變（**虛晃**）
- 定形時不定期有一道**掃光**滑過表面；殼有時剝起一片皮，像煙一樣流走再長回去（**剝落**）。每次變化都換一組顏色
- 有人站到前面時，畫面上不會出現人形。形體沿著那個人的**視線**被推開，殼上開出一個洞；一小群**追隨粒子**脫離形體繞著他打轉，待得越久，跟過來的越多。剛到時，世界有時會因此提早變化
- 背景是帶短殘影的**塵埃**，像從一支不規則來回擺動的鏡頭看出去：近的與遠的往相反方向滑

用詞定義在 [`GLOSSARY.md`](GLOSSARY.md) 的「無名之物」一節。

## 怎麼做的

- **Unity 6000.3.15f1、URP**。粒子不經 VFX Graph：512 × 384（196,608）顆有慣性的粒子用 compute shader 逐影格模擬，再用自訂 shader 畫成加法混合的光點；後製是 URP Volume 的 Bloom 與 Tonemapping
- **生物與殼是同一群粒子**：每個影格算出一個目標把粒子拉過去，生物是團塊與觸鬚組成的場的等值面，殼是加上葉瓣、皺褶、凹陷、扭轉的變形球面，轉場時兩者混合。所以換一類形體是一段連續的動作，而不是兩套系統互相淡入淡出
- **殼的硬輪廓**：殼上每顆粒子有自己固定的方位，表面才勻、邊緣才利；讓它們像生物一樣自由流動時，殼會皺成生物的樣子
- **指揮（Conductor）**：決定世界何時、怎麼變的部分是不碰場景的純 C#（`Conductor.cs`、`Forms.cs`），亂數可指定種子。EditMode 測試用固定種子快轉 15–30 分鐘的模擬時間，檢查轉場不會連續重複同一種、定形長短夠不規則又有上下限、只有殼會剝落、合體模式真的會在兩類之間轉換；另外隨機產生 3,000 個生物與 400 個殼，檢查都放得進同一個畫面框、沒有哪一種系統性地偏小
- **觀眾只是一筆「在場」資料**：視線的起點與方向、視線與形體所在平面的交點、淡入淡出的強度、停留秒數。沒有人像遮罩，之後接 webcam 只需要估出人在哪、看哪裡，不必做人像分割（[ADR 0002](docs/adr/0002-nameless-world-reads-presences-only.md)）
- **塵埃的殘影**：原型靠不清除的畫面緩衝慢慢淡出；Unity 版改成把每顆塵埃依記住的最近 64 個影格的鏡頭位置重畫、按衰減加權，殘影的長短以時間計，不綁影格率
- 程式在 [`Assets/_Project/Nameless/`](Assets/_Project/Nameless/)，從網頁原型（WebGL2）移植而來

## 過程

這個作品的方向換過一次，兩條路都留著。

- **前一個方向：流場線條的身影**。觀眾化成發光線條構成的身影，交會時互染顏色。我用一連串 30–60 分鐘的素描（[`docs/sketches/`](docs/sketches/)）一層層學 VFX Graph、compute shader、ping-pong 場，做到 09 的光紗待機畫面。這條路現在擱置，但沒有作廢：素描與 `Scenes/Main.unity` 還在 main，沒收尾的身影看樣在 `archive/lookdev` 分支，光紗對觀眾的反應實驗在 `archive/idle-notice` 分支
- **轉向無名之物**：從零開始，先做一個網頁原型並排比較三個方向（無名生物、奇異吸子、有機殼），經過幾輪看樣收斂成生物與殼的「合體」，再移植進 Unity。決定不畫人形，是因為畫出人形會打斷粒子的呼吸感
- **決策留紀錄**：每個重要的取捨寫成 ADR（[`docs/adr/`](docs/adr/)，0002 取代 0001 的理由與被放棄的選項都在裡面），用詞統一在 [`GLOSSARY.md`](GLOSSARY.md)，進度與架構在 [`docs/ROADMAP.md`](docs/ROADMAP.md)

網頁原型 [`docs/lookdev/nameless.html`](docs/lookdev/nameless.html) 是單一檔案，下載後用支援 WebGL2 的瀏覽器開啟即可。下方的列可以切換方向，勾「滑鼠＝有人」模擬觀眾，「顯示事件」看當下的事件與形態。

## 執行

1. 用 Unity 6000.3.15f1 開啟專案（`Packages/manifest.json` 裡有一個從 GitHub 安裝的編輯器工具套件，電腦需要裝 git）
2. 開 `Assets/_Project/Scenes/Nameless.unity`，按 Play
3. 滑鼠移進 Game View，就等於有一位觀眾站到鏡子前，視線是從鏡頭穿過游標的那條線；移出 Game View 就是離開
4. 場景裡 `Nameless World` 物件的 Inspector 可以切換模式（合體／無名生物／有機殼）、打開「顯示事件」，以及調整塵埃的數量與亮度

測試：Window › General › Test Runner › EditMode，無名之物的測試是 `FlowMirror.Tests` 底下的 `NamelessConductorTests` 與 `NamelessFormsTests`。

目前只有一位觀眾（滑鼠），效能還沒有實測，webcam 是之後的事。
