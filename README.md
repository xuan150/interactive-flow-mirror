# Interactive Flow Mirror

**Afterglow** — 一個以流場線條呈現身影的互動鏡像裝置原型（Unity VFX Graph）

> 你有你的，我有我的，方向；
> 你記得也好，最好你忘掉，
> 在這交會時互放的光亮！
> —— 徐志摩〈偶然〉

## 構想

一面 4m × 2m 的 LED「鏡子」。觀眾走進範圍時，螢幕上浮現由流動線條構成的身影：

- 有人進場時會產生漣漪，多人的漣漪會擴散、干涉
- 交會時，流場互相牽引，顏色互相滲透，分開後各自帶走一點對方的顏色
- 人離開後，軌跡慢慢沉澱、淡出
- 沒有人時，線條和微光自己漂浮

目前在電腦上用滑鼠假人模擬，之後可能改用 webcam 讓真人入鏡。

## 環境

- Unity 6000.3.15f1（URP）
- Visual Effect Graph
