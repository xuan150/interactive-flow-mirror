# VFX 數學積木手冊

VFX Graph 的 Operator 不用「發明數學」：十來個積木，用幾個固定配方組合。每遇到新積木或新配方就補進來。

## 想新效果的流程

1. **先用中文一句一句寫**想要的事（「波峰在哪」「我離它多遠」「近的亮遠的暗」）
2. 每一句通常對應一兩個積木，再看是不是下面某個**配方**
3. **一次接一個積木就看畫面**，確認那一步對了再接下一步

## 積木

分兩類：**產生值的**（從無到有），和**改變值的**（把已有的值變形）。

### 產生值

| 積木 | 給它什麼 → 得到什麼 | 用過的地方 |
|---|---|---|
| **Get Attribute** | 粒子自己的資料（spawnIndex、stripIndex、particleIndexInStrip、position…） | 第幾條線、線上第幾點 |
| **Total Time** | 特效開始後的秒數，一直變大 | 所有會動的東西 |
| **Periodic Total Time** | 每 Period 秒循環一次，在 Range 間走一遍 | 呼吸的波峰位置 |
| **Noise**（Perlin） | 座標 → 平滑的隨機值。座標近，值就近；座標裡放時間就會動 | 起伏、遮罩 |
| **Sine** | 值 → 規律地來回擺盪（-1 ~ 1） | |

### 改變值

| 積木 | 它對值做什麼 | 用過的地方 |
|---|---|---|
| **Lerp / Remap** | 換範圍（0~1 → -11~11） | 把點排成線 |
| **Multiply** | 放大縮小；乘 0~1 ＝**音量鈕** | 振幅、權重 |
| **Add** | 把兩個效果**疊在一起** | 原位 ＋ 起伏 ＋ 呼吸 |
| **Subtract ＋ Absolute** | 兩個值**差多遠**（不分正負） | 離波峰多遠 |
| **Smoothstep** | **柔和門檻**：低於下限＝0、高於上限＝1、中間平滑 S 曲線；輸出永遠 0~1 | 遮罩切區塊、隆起的邊緣 |
| **One Minus** | **反過來**：1 ↔ 0 | 讓波峰處＝1 |
| **Floor** | 無條件捨去成整數 → 切成一格一格 | 第幾條線 |
| **Divide** | 除法，常用來把整數變成 0~1 的比例 | index ÷ 總數 |

### 長得像但不同：Noise vs Smoothstep

| | Noise | Smoothstep |
|---|---|---|
| 角色 | **原料**：從座標「長出」變化 | **篩子／調光器**：把已有的值切成有／沒有 |
| 隨機嗎 | 是（平滑的隨機） | 否，同樣輸入永遠同樣輸出 |
| 什麼時候用 | 「我需要變化、不規則」 | 「我已經有一個值，要給它一個柔和的邊界」 |
| 常一起用 | Noise 產生原料 → Smoothstep 切出區塊（②+ 的局部起伏） | |

判斷法：手上**還沒有值** → 找「產生值」的積木；**已經有值要加工** → 找「改變值」的積木。

## 配方

| 配方 | 組法 | 用在 |
|---|---|---|
| **某處才有** | `效果 × 遮罩（0~1）` | 局部起伏；之後的身影（遮罩改由人決定） |
| **以某點為中心的柔和隆起** | `距離 → Smoothstep → One Minus` | 呼吸、流光；之後每個人的影響範圍、漣漪 |
| **會移動的圖樣** | 位置減時間：`f(x − 時間)`，或讓中心點隨時間走 | 呼吸掃過 |
| **疊加** | 每個效果各算各的，最後全部 Add | 原位 ＋ 起伏 ＋ 呼吸 |
| **有基礎值的強調** | `基礎 ＋ 強調 × 強度` | 流光（沒光帶時線不會全暗） |
| **範圍超出畫面＝休息** | 讓循環的 Range 跑出可見範圍 | 呼吸之間的停頓 |
| **用值查漸層** | 把 0~1 的值接到漸層 Block 的 Sample Time（Sample Mode: Custom） | 流光：離波峰的距離查出亮色／基礎色，顏色與亮度分布直接在漸層上畫 |
| **固定隊形的錯開** | 週期相同，加**相位／位置偏移**：`循環值 + 偏移(index)`；偏移不接時間 | 流光每條線參差掃過 |

**陷阱：錯開週期會越跑越散。** 每條線用不同 Period（`8 + index × 0.2`）＝時鐘快慢不同，一開始幾乎對齊，差距每圈累積，久了完全分開。要固定隊形就讓週期相同、只錯開位置。

## 學習資源

- [Graphtoy](https://graphtoy.com)：打 `smoothstep(0, 2.5, abs(x))` 立刻畫出曲線，用 `t` 會動。**理解積木最快的地方**
- [The Book of Shaders](https://thebookofshaders.com)（有中文）：第 5 章 Shaping Functions＝這套積木；第 11–13 章 noise
- Freya Holmér〈Shaders for Game Devs〉（YouTube）：圖解這些函數
- VFX Graph 的 Learning Templates：打開 graph 一個節點一個節點拆
