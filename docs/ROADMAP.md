# Roadmap

> 任何時候（新對話、compact 後、跳著做）都從這份開始對照。

## 構想

一面 4m × 2m、立在地上的 LED「鏡子」。觀眾走進範圍，螢幕上浮現由流動線條構成的身影；有人進場產生漣漪，多人交會時彼此影響。
實體案不會進行，這是**個人概念作品**：在 Unity 裡用滑鼠假人模擬，效果好再考慮 webcam 真人入鏡。

## 已確定的設計決策

- Unity 6000.3.15f1，3D (URP)，主力 **VFX Graph**
- 畫面 2:1（Game View 1920×960），正交相機 Size 5（可視範圍 20×10 單位），鏡像（左右翻轉，在輸入端處理）
- **交付**：30–60 秒作品影片，用編排走位的假人錄製；webcam 之後再說
- **視覺方向**：見下方「目標畫面」一節（2026-10-27 腦力激盪）。01–06 的錨定水平線、黑色剪影、漣漪、漩渦都是探索紀錄；技術（人物 buffer、ID 遮罩、顏色交換、ping-pong 場）沿用
- **人的呈現**：不投真人影像，認得出是人但沒有細節
- **待機畫面**：07a、07b、07c 與 09 四個待機版本看完後選定 **09 光紗**（2026-11-02）
- 用詞（觀眾、身影、光絲、亂絲、交會、大理石紋）見 [GLOSSARY](../GLOSSARY.md)
- 視覺層與輸入來源的接縫：見 [ADR 0001](adr/0001-visuals-read-person-buffer-and-id-mask.md)

## 架構：單向資料流

```
[輸入層]  →  [人物狀態]  →  [場（GPU）]  →  [渲染（VFX Graph）]  →  [後製]
滑鼠假人      Person 清單     漣漪場           線條粒子(Strip)        Bloom
(之後 webcam) + 身影 ID 遮罩   痕跡場           讀取以上全部            (選配 LED 點陣)
```

| 層 | 內容 | 技術 |
|---|---|---|
| 輸入 | `MousePersonSource`：左鍵新增/拖曳人、Delete 移除；把剪影貼圖蓋印到 ID 遮罩 | C# + 簡單 shader |
| 人物狀態 | `PersonTracker`：持有人物清單、算速度、顏色交換、上傳 GraphicsBuffer | 純 C#（顏色交換寫成純函式，有 EditMode 測試） |
| 場 | **漣漪場**（04，目前退場）：波動方程 ping-pong RT（1/4 解析度）<br>**大理石紋場**（08 看樣）：只平流、不擴散的顏色場，交會時兩人之間 | Compute Shader 或 Custom Render Texture |
| 渲染 | 極淡細密的背景流線＋光絲構成的身影（07 看樣定案）；顏色取自人物（本色／帶著的顏色）與大理石紋場 | VFX Graph |
| 後製 | URP Volume Bloom；之後選配 LED 點陣 | URP Post-processing |

## 目標畫面（草案，看樣後定案）

2026-10-27 腦力激盪的結論。看樣做完後**回到那次腦力激盪的對話**挑勝出者，再接 `/to-spec` → `/to-tickets`。

**情緒核心**：相遇為主、好玩為輔。任何時候畫面只有一個主角：身影。

### 三個候選共用

- **背景**：極淡、細密的流線（[參考](refs/lines-fog-cursor.png)），緩慢起伏、呼吸，不能完全靜止
- **身影**：好幾條光絲像辮子一樣疊著包覆輪廓，加上不成圈的亂絲；慢慢長成，不突然出現
- **色彩**：獨處時近乎無色（銀白、淡金）；每人有隱藏的本色，交會時才被照出（沿用 06 的本色／帶著的顏色）。調色盤集中在 `PersonTracker.Palette` 一處，之後要對主視覺配色只改這裡
- **動作語彙**：靜止 → 光絲收緊編齊、流光沿絲繞行；移動 → 光絲被甩在後面鬆成飄帶、亂絲變多；快速 → 部分光絲甩斷、淡掉
- **交會**：光絲從包覆自己岔出，流到對方身影最外層；一人可同時岔向多人。分開時拉長、斷掉，斷絲留在對方身上慢慢褪色
- **大理石紋**：只在交會時、兩人之間出現；顏色只平流不擴散（不會變髒），最後淡成黑。03 的漩渦退居成梳出紋路的那股流
- 04 漣漪、03 漩渦不再是獨立可見的效果（程式保留，需要時再叫回）

### 三個身影候選

| | 07a 撈 | 07b 生 | 07c 霧中 |
|---|---|---|---|
| 光絲從哪來 | 進場時附近的背景流線慢慢彎過來，纏成他的光絲 | 從身體表面慢慢吐出（像蠶吐絲）；背景流線只繞開 | 同撈 |
| 身體內部 | 稀疏光點，緩慢呼吸 | 暗，被光絲包著 | 暗 |
| 背景 | 純流線 | 純流線 | 流線下墊一層極淡色霧（調色盤載體） |
| 看點 | 人是環境的一部分 | 人是光的來源 | 調色盤氣氛 |

### 看樣計畫

1. **07 準備**（main，非拋棄式）：畫質修正＋走位編排（照時間軸自動移動假人；看樣與最終影片共用，四張看樣才能跑同一段走位）
2. **07a–c 身影看樣**：只比身影。走位含待機、單人進場／靜止／移動、兩人交會與分開、多人（[07 的走位表](sketches/07-prep.md#走位輸入層)）。各 1–2 小時、拋棄式，從 `Scenes/Main.unity` 複製，錄全段走位（約 47 秒，螢幕錄影）
3. **08 大理石紋看樣**：流體只平流，獨立一張（三個候選共用，不放進比較）

**看樣怎麼並行**（Unity 一次只開一個編輯器）：四張共用一條 `prototype/lookdev` 分支（從 07 完成後的 main 開），各放 `Sketch_07a/07b/07c/08` 資料夾。需要的程式各複製一份並改名（C# 用 `FlowMirror.Lookdev07a` 這類 namespace，HLSL／VFX 檔名加前綴），main 上的共用程式只讀不改。session 可以同時開著討論、寫，但輪流進 Unity；任何一張編譯錯誤會擋住全部，改完要確認 Console 乾淨。每個 session 只 commit 自己的資料夾。

**評分標準**（影片並排看）：① 構築感：身影成形的過程美不美 ② 交會可讀性：一眼看得出兩人之間有連結 ③ 獨處撐不撐得住 ④ 待機（沒有身影）會不會單調 ⑤ 多人時會不會雜亂

### 線條畫質（2026-10-27 檢查，07 已修，見 [07-prep](sketches/07-prep.md#畫質)）

「線不漂亮」主要是設定問題：
- `PC_RPAsset` MSAA 關、相機 AA None；線寬 0.015 ≈ 1.4 px，SubpixelAA 只在 < 1 px 才作用 → 階梯、粗細忽變、閃爍，Bloom 再放大
- Output 還掛著範本的 `DefaultDot` 貼圖（Stretch），不可控地調暗線
- 兩個 Multiply 漸層讓平時的線只剩暗藍（約 0.27），呼吸峰值單通道衝到 4+；Additive＋Bloom（強度 4、門檻 0.8）→ 暗藍裡夾白斑
- 真正的做法極限只有一條：每段 ≈ 7 px，推大時折出角；錨定的線推遠會互相超車（05 已撞過）

## 點子池

還沒排進 sketch 的點子，組合 Main 時評估。辮子、發光細絲、牽線已融進「目標畫面」（光絲、亂絲、交會）；痕跡場被大理石紋取代。

- **辮子（意外發現）**：拔掉「原位 y」，讓 `y = 起伏 noise × 權重`。平靜區所有線疊成**一條線**，起伏區因為 noise 仍用各自原位 y 取樣而**散開交織成一束辮子**，再收回一條。「一條線分岔、交會、收束」。保存在 `Assets/_Project/VFX/Ideas/Idea_Braid.vfx`（02b 數值＋20 條線）；圖：[graph](refs/ideas/braid-graph.png)、[成果](refs/ideas/braid-result.png)
  - 可能用法：待機時一條線，有人進場時從他身上分岔成辮子；或兩人交會時兩束辮子纏在一起
- **發光細絲**（[參考](refs/particles-filaments-purple.png)）：幾十萬顆極小、半透明粒子被流場推著，擠在匯聚處的就疊加成亮絲。Sketch 01 Frequency 調高時「粒子被困住」就是雛形。可用在交會（兩人之間長出細絲）或痕跡（走過處沉澱成紋路再散開）
- **幽靈訪客**：待機時偶爾在隨機位置冒出一圈很淡的漣漪，像剛有人經過（需要 04 漣漪場）
- **牽線**：距離夠近的兩人之間長出細線，走遠時拉長、變細、斷掉
- **抬手**：送出較大的漣漪（假人用右鍵模擬）
- **集體共振**：很多人同時靜止時，漣漪干涉成克拉德尼圖形般的穩定幾何圖樣
- **彗星尾巴**：02 的線改成固定長度、跟著筆尖跑的尾巴（墨跡壽命 = min(尾巴秒數, 筆尖剩餘壽命)）
- **漩渦強度跟移動速度連動**：滑鼠／人移動越快漩渦越強，停下來變弱（互動小彩蛋）
- **痕跡場（06 原本要做、延後）**：人走過塗上自己的顏色、慢慢沉澱淡出。做法可抄 04 的 ping-pong（衰減 RT），線條取樣後加進 `glow`（見 [06 ④](sketches/06-exchange.md)）
- **人形籠子（05 意外發現）**：線條上的點被左右、上下一起推離身體（推超過點距），線來回折返，在人身上罩出一個人形的鋸齒籠子。可當「被困住」或特殊狀態的語彙。重現：`Silhouette.hlsl` 改回 `p -= grad * push`（x、y 都推）、push 2 以上
