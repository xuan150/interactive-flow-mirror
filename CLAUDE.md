# Interactive Flow Mirror

Unity 6000.3.15f1 (URP) + Visual Effect Graph. Interactive mirror installation prototype: viewers appear as flow-field line silhouettes; ripples on entry, color exchange and vortex pull on encounter, fading traces after leaving. Fake people are driven by the mouse for now.

**Start every session from `docs/ROADMAP.md`**: architecture, design decisions, and sketch progress live there. Each sketch's steps and the user's chosen values live in `docs/sketches/`. Work is taught sketchbook-style: guide the user through the Unity editor step by step, explain concepts as they come up.
